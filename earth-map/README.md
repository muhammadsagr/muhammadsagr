# 🌍 أرض ماب — خريطة + كرة أرضية تفاعلية

موقع ويب متكامل يجمع بين فكرة **خرائط الطرق** (بحث، اتجاهات، أماكن قريبة) و**الكرة الأرضية ثلاثية الأبعاد** (طيران فوق العالم، إمالة، جولات سينمائية) في واجهة عربية واحدة.

## التشغيل
- **أسهل طريقة:** افتح `earth-map/index.html` بالضغط عليه مرتين (يحتاج اتصالاً بالإنترنت).
- أو شغّل خادماً محلياً (أفضل لبعض المتصفحات):
  ```bash
  cd earth-map
  python -m http.server 8000
  # ثم افتح http://localhost:8000
  ```
- لا يحتاج أي تثبيت أو مفاتيح API. يمكن رفعه كما هو على GitHub Pages أو Netlify.

|---|---|

| 🔍 البحث | عن مدن، عناوين، معالم، أو إحداثيات مثل `24.7136, 46.6753` |

| 🧭 الاتجاهات | بالسيارة أو مشياً أو بالدراجة، مع تعليمات خطوة بخطوة بالعربية |
| 🍽️ أماكن قريبة | مطاعم، مقاهي، فنادق، وقود، مستشفيات، صيدليات، مساجد، صرّافات، حدائق، متاحف |
| ⭐ أماكني | حفظ الأماكن مع ملاحظات، وتصديرها GeoJSON |
| 📏 القياس | المسافة والمحيط والمساحة |
| ✈️ جولات | جولة سينمائية بين أشهر معالم العالم مع دوران حول كل معلم |
| 🛰️ الطبقات | قمر صناعي، طرق، تضاريس، OpenStreetMap، ليلي، فاتح |
| 🌗 الكرة الأرضية | إمالة 3D، منظر الشارع، تدوير تلقائي، الليل والنهار، الغلاف الجوي، حفظ صورة |
| 🔗 مشاركة | رابط يحفظ الموقع والوضع والطبقة والدبوس |
| 📱 متجاوب | يعمل على الهاتف (لوحة سفلية) وسطح المكتب |

### التضاريس والمباني ثلاثية الأبعاد (اختياري)
أنشئ حساباً مجانياً على [Cesium ion](https://ion.cesium.com/signup)، وانسخ المفتاح (Access Token) إلى
**القائمة ← الإعدادات**. بعدها يمكن تفعيل:
- التضاريس الحقيقية (الجبال والوديان)
- مباني OpenStreetMap المجسمة، أو المدن الواقعية ثلاثية الأبعاد (Google Photorealistic 3D Tiles)

## الاختصارات
`/` بحث · `M` تبديل الخريطة/الأرض · `L` الطبقات · `N` الشمال · `T` الإمالة · `+`/`-` تكبير · `Esc` إغلاق

## هيكل الملفات
```
earth-map/
├── index.html        # الصفحة والواجهة
├── css/style.css     # التنسيقات (داكن/فاتح، متجاوب)
└── js/
    ├── util.js       # أدوات: المسافات، المساحات، التنسيق، التخزين
    ├── services.js   # البحث، الاتجاهات، الطقس، الأماكن القريبة، ويكيبيديا
    ├── engines.js    # المحركان 2D/3D وطبقة موحّدة لرسم العناصر في كليهما
    └── app.js        # منطق الواجهة واللوحات والأدوات
```
