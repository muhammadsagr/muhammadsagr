# 👥 لوحة معلومات الموارد البشرية (Python + Streamlit)

> **أسهل طريقة:** افتح الملف `hr_dashboard.html` بالضغط عليه مرتين، فيفتح في المتصفح مباشرة دون تثبيت أي شيء.
> هو نسخة HTML/CSS/JavaScript من نفس اللوحة.

تطبيق ويب بلغة بايثون يعرض لوحة معلومات (Dashboard) تفاعلية لبيانات موارد بشرية **افتراضية** (500 موظف).

## المميزات
- **مؤشرات رئيسية:** إجمالي الموظفين، الموظفون النشطون، تعيينات آخر 12 شهر، معدل الدوران، متوسط الراتب، متوسط الأداء.
- **نظرة عامة:** الموظفون حسب القسم والمدينة والمؤهل، التوزيع حسب الجنس، توزيع الأعمار، التعيينات مقابل ترك العمل سنوياً.
- **الرواتب والأداء:** توزيع الرواتب حسب القسم، تقييمات الأداء، ملخص الأقسام، علاقة التدريب بالأداء.
- **ترك العمل:** الأسباب، النسبة حسب القسم، آخر الحالات.
- **بيانات الموظفين:** جدول مع بحث وتحميل CSV.
- **إضافة موظف:** نموذج لإضافة موظف جديد تنعكس بياناته فوراً على اللوحة.
- **فلاتر جانبية:** القسم، المدينة، الجنس، تاريخ التعيين + زر لتوليد بيانات جديدة.
- **🤖 اسأل البيانات:** فريق Agents مبني على Claude يجيب عن أسئلتك عن البيانات والسياسات (انظر القسم أدناه).

## هيكل المشروع
```
data_generator.py   # التطبيق كاملاً: البيانات الافتراضية + لوحة المعلومات
hr_agents/          # فريق الـ Agents
  config.py         #   النموذج والمفتاح والحدود
  tools.py          #   الدوال الحسابية (pandas) التي يستدعيها الـ Agents
  agents.py         #   تعريف الـ Agents الخمسة وحلقة استدعاء الأدوات
  orchestrator.py   #   المنسّق والتشغيل المتوازي
policies/           # سياسات افتراضية: الإجازات، العمل عن بُعد، التدريب
tests/              # اختبارات pytest (لا تحتاج مفتاح API)
requirements.txt    # المكتبات المطلوبة (تُثبَّت تلقائياً عند التشغيل)
.vscode/launch.json # إعداد التشغيل من Visual Studio Code (F5)
```

## التشغيل في Visual Studio Code
1. ثبّت [Python 3.10+](https://www.python.org/downloads/) وإضافة **Python** من Microsoft داخل VS Code.
2. افتح مجلد المشروع: `File > Open Folder`.
3. افتح الطرفية `Terminal > New Terminal` ونفّذ:
   ```bash
   python -m venv .venv
   # Windows:
   .venv\Scripts\activate
   # macOS / Linux:
   source .venv/bin/activate

   pip install -r requirements.txt
   ```
4. اختر المفسّر: `Ctrl+Shift+P` ← `Python: Select Interpreter` ← اختر `.venv`.
5. شغّل التطبيق بالضغط على **F5** (إعداد "تشغيل لوحة الموارد البشرية")، أو من الطرفية:
   ```bash
   python data_generator.py
   ```
   أو افتح `data_generator.py` واضغط زر **Run ▶**.
6. سيفتح المتصفح تلقائياً على `http://localhost:8501`.

> لحفظ البيانات في ملف CSV استخدم زر "تحميل البيانات" في تبويب بيانات الموظفين.

## ملاحظة عن Visual Studio (وليس VS Code)

## 🤖 فريق الـ Agents (تبويب "اسأل البيانات")
منسّق يستقبل سؤالك ويوزّعه على 5 متخصصين، يعملون على البيانات **بعد تطبيق الفلاتر الجانبية**:

| الـ Agent | المهمة |
|---|---|
| 📉 محلل الدوران | معدلات الدوران حسب القسم، أسباب ترك العمل، الاتجاه السنوي، أعلى 3 مخاطر |
| 🔮 متنبئ الاستقالات | درجة خطر 0-100 لكل موظف نشط بقواعد شفافة (لا تستخدم الجنس أو العمر أو المدينة) |
| ⚖️ مراجع الرواتب | فجوة الرواتب بين الجنسين داخل نفس الوظيفة، الرواتب حسب المؤهل والأداء |
| 📘 مساعد السياسات | يجيب من ملفات `policies/` فقط ويذكر الملف المصدر |
| 📝 كاتب التقارير | تقرير تنفيذي بصيغة Markdown قابل للتنزيل |

```
سؤال المستخدم ─► 🧭 المنسّق ─┬─► 📉 محلل الدوران ──┐
                            ├─► 🔮 متنبئ الاستقالات ├─► (بالتوازي) ─► 📝 كاتب التقارير ─► الإجابة
                            ├─► ⚖️ مراجع الرواتب ───┘
                            └─► 📘 مساعد السياسات
كل متخصص ─► أدوات pandas في hr_agents/tools.py ─► أرقام دقيقة (النموذج لا يحسب الأرقام بنفسه)
```

### نسخة الويب (ملف HTML)
الفريق نفسه موجود أيضاً في `hr_dashboard.html`، في قسم **"🤖 اسأل البيانات"** أسفل الصفحة، ويعمل بفتح الملف في المتصفح دون بايثون:
1. افتح `hr_dashboard.html` في المتصفح.
2. من **⚙️ الإعدادات** أدخل مفتاح API واختر النموذج. اختيارياً فعّل "تذكّر المفتاح في هذا المتصفح".
3. اكتب سؤالك أو اضغط أحد الأسئلة الجاهزة.

- المفتاح يُرسل مباشرة من متصفحك إلى `api.anthropic.com` فقط، ويُحفظ (إن اخترت) في `localStorage` لهذا المتصفح.
- **لا تشارك الملف أو جهازك وفيه مفتاح محفوظ، ولا ترفعه على موقع عام**، فمن يفتح الصفحة يستخدم مفتاحك. للمشاركة مع آخرين استخدم نسخة Streamlit حيث يبقى المفتاح على الخادم.
- الأدوات والبرومبتات والضوابط مطابقة لنسخة بايثون. السياسات منسوخة داخل الملف من مجلد `policies/`، فإذا عدّلت السياسات فحدّث النسخة داخل الملف أيضاً (الثابت `POLICIES`).

### إعداد المفتاح (نسخة Streamlit)
احصل على مفتاح من [console.anthropic.com](https://console.anthropic.com)، ثم استخدم **إحدى** الطريقتين:

```bash
# Windows (PowerShell)
$env:ANTHROPIC_API_KEY="sk-ant-..."
# macOS / Linux
export ANTHROPIC_API_KEY="sk-ant-..."
```

أو أنشئ الملف `.streamlit/secrets.toml` (مُستثنى من git):
```toml
ANTHROPIC_API_KEY = "sk-ant-..."
```

بدون مفتاح تعمل اللوحة كاملة، ويعرض التبويب رسالة إرشادية فقط.

### أمثلة أسئلة
- لماذا الدوران مرتفع في المبيعات؟
- من الموظفون المعرضون للاستقالة في تقنية المعلومات؟
- هل توجد فجوة رواتب بين الجنسين؟
- كم يوم إجازة سنوية يحق لي؟
- اكتب لي تقريراً شهرياً للإدارة

### إعدادات اختيارية (متغيرات بيئة)
| المتغير | الافتراضي | الوصف |
|---|---|---|
| `HR_AGENTS_MODEL` | `claude-sonnet-5-5` | النموذج المستخدم (مثلاً `claude-opus-5-5` لجودة أعلى أو `claude-haiku-5-5` لتكلفة أقل) |
| `HR_AGENTS_EFFORT` | `medium` | مستوى جهد المتخصصين: `low` / `medium` / `high` |
| `HR_AGENTS_ORCHESTRATOR_EFFORT` | `medium` | مستوى جهد المنسّق |

### الضوابط
- كل رقم يأتي من دالة pandas، والنموذج يفسّر النتائج فقط.
- أسماء الموظفين لا تُرسل إلا لمتنبئ الاستقالات.
- كل توصية مكتوب بجانبها "تتطلب مراجعة بشرية"، ولا يتخذ أي Agent قراراً بشأن موظف.
- حد أقصى 8 جولات أدوات لكل Agent، ومهلة 120 ثانية لكل طلب، ورسائل خطأ واضحة بالعربية.
- عند رفض النموذج طلباً لأسباب السلامة، يُعاد تشغيله تلقائياً على نموذج بديل (server-side fallback).
