# 👥 لوحة معلومات الموارد البشرية (Python + Streamlit)

> **أسهل طريقة:** افتح الملف `hr_dashboard.html` بالضغط عليه مرتين، فيفتح في المتصفح مباشرة دون تثبيت أي شيء.
> هو نسخة HTML/CSS/JavaScript من نفس اللوحة.

تطبيق ويب بلغة بايثون يعرض لوحة معلومات (Dashboard) تفاعلية لبيانات موارد بشرية **افتراضية** (500 موظف).

## المميزات
- **مؤشرات رئيسية:** إجمالي الموظفين، الموظفون النشطون، تعيينات آخر 12 شهر، معدل الدوران، متوسط الراتب، متوسط الأداء.
- **نظرة عامة:** الموظفون حسب القسم والمدينة والمؤهل، التوزيع حسب الجنس، توزيع الأعمار، التعيينات مقابل ترك العمل سنوياً.
- **الرواتب والأداء:** توزيع الرواتب حسب القسم، تقييمات الأداء، ملخص الأقسام، علاقة التدريب بالأداء.
- **ترك العمل:** الأسباب، النسبة حسب القسم، آخر الحالات.
- **بيانات الموظفين:** جدول مع بحث وتحميل CSV.
- **إضافة موظف:** نموذج لإضافة موظف جديد تنعكس بياناته فوراً على اللوحة.
- **فلاتر جانبية:** القسم، المدينة، الجنس، تاريخ التعيين + زر لتوليد بيانات جديدة.

## هيكل المشروع
```
data_generator.py   # التطبيق كاملاً: البيانات الافتراضية + لوحة المعلومات
requirements.txt    # المكتبات المطلوبة (تُثبَّت تلقائياً عند التشغيل)
.vscode/launch.json # إعداد التشغيل من Visual Studio Code (F5)
```

## التشغيل في Visual Studio Code
1. ثبّت [Python 3.10+](https://www.python.org/downloads/) وإضافة **Python** من Microsoft داخل VS Code.
2. افتح مجلد المشروع: `File > Open Folder`.
3. افتح الطرفية `Terminal > New Terminal` ونفّذ:
   ```bash
   python -m venv .venv
   # Windows:
   .venv\Scripts\activate
   # macOS / Linux:
   source .venv/bin/activate

   pip install -r requirements.txt
   ```
4. اختر المفسّر: `Ctrl+Shift+P` ← `Python: Select Interpreter` ← اختر `.venv`.
5. شغّل التطبيق بالضغط على **F5** (إعداد "تشغيل لوحة الموارد البشرية")، أو من الطرفية:
   ```bash
   python data_generator.py
   ```
   أو افتح `data_generator.py` واضغط زر **Run ▶**.
6. سيفتح المتصفح تلقائياً على `http://localhost:8501`.

> لحفظ البيانات في ملف CSV استخدم زر "تحميل البيانات" في تبويب بيانات الموظفين.

## ملاحظة عن Visual Studio (وليس VS Code)
إذا كنت تستخدم **Visual Studio 2022**: ثبّت حمل العمل *Python development*، ثم
`File > Open > Folder`، وافتح الطرفية من `View > Terminal` ونفّذ الخطوات 3 و 5 نفسها.

# ⚖️ ميزان — منصة تحليل المخاطر

مشروع ثانٍ في نفس المستودع، داخل المجلد `mizan/`. هذه **المرحلة 1**: جمع البيانات، والتخزين، ولوحة للأسعار والعوائد.

> البيانات التجريبية مُولَّدة وليست أسعار سوق حقيقية. ميزان أداة تحليل وتعلّم، وليس نصيحة استثمارية.

## التشغيل
```bash
pip install -r requirements.txt
python mizan/app.py
```

### نسخة الموقع (HTML و CSS و JavaScript)
المجلد `mizan_web/` نسخة كاملة من ميزان تعمل في المتصفح مباشرة، بلا بايثون ولا خادم:
**افتح الملف `mizan_web/index.html` بالضغط عليه مرتين.** فيه ثلاثة أقسام: الأسعار والعوائد، ومحاكاة التهرب الضريبي، وكشف الاحتيال.
المحاكاة كلها تُحسب داخل المتصفح بنفس منطق ملفات بايثون، والرسوم مرسومة بـ SVG دون مكتبات خارجية.
لنشره كموقع على الإنترنت ارفع المجلد كما هو إلى أي استضافة ملفات ثابتة، مثل GitHub Pages أو Netlify.
الجزء الوحيد غير الموجود في نسخة الموقع هو المخزن الزمني وجامع البيانات وملفات CSV، لأنها تحتاج نظام ملفات.
أو من VS Code: اضغط **F5** واختر «تشغيل ميزان». بعد فتح اللوحة اضغط **🔄 تحديث البيانات** في الشريط الجانبي.

## مصادر البيانات
- **بيانات تجريبية:** ستة أصول مُولَّدة بحركة براونية هندسية، مع عامل سوق مشترك يصنع الارتباط بينها، وفترات تذبذب مرتفع، وقفزات نادرة. نفس اليوم يعطي نفس السعر دائماً.
- **ملفات CSV:** ضع ملفاً لكل رمز داخل المجلد `mizan_csv/` (مثل `AAPL.csv`)، بالأعمدة `Date, Open, High, Low, Close, Volume`. إذا وُجد عمود `Adj Close` يُستخدم تلقائياً. يمكنك تنزيل هذه الملفات من Yahoo Finance أو Stooq.

## المكوّنات
| الملف | الوظيفة |
|---|---|
| `mizan/store.py` | مخزن سلاسل زمنية مكتوب من الصفر: ملفات ثنائية تُكتب بالإلحاق فقط، و CRC32 لكل سجل، واسترداد تلقائي من الكتابة المقطوعة، وبحث ثنائي للنطاقات، وضغط ذري |
| `mizan/sources.py` | مصادر البيانات (تجريبية و CSV) بواجهة موحّدة |
| `mizan/collector.py` | جامع غير متزامن (`asyncio`) يجلب عدة رموز بالتوازي، ويحدّث بشكل تزايدي، ويعزل أخطاء كل رمز عن غيره |
| `mizan/analytics.py` | العوائد، والتذبذب، والتراجع، والعائد السنوي المركب، ونسبة شارب |
| `mizan/app.py` | نقطة التشغيل والتنقل بين الصفحات |
| `mizan/views/prices.py` | صفحة الأسعار: الملخص، والأداء، والتراجع والتذبذب المتحرك، ومصفوفة الارتباط، وتنزيل البيانات |
| `mizan/views/fraud_sim.py` | صفحة محاكاة التهرب الضريبي والاحتيال المالي |

## 🕵️ محاكاة التهرب الضريبي والاحتيال المالي
صفحة ثانية في ميزان، هدفها **الكشف وتقييم السياسات الرقابية** على بيانات مُولَّدة بالكامل، على غرار أدوات البحث PaySim و AMLSim.

**التهرب الضريبي** (`mizan/fraudsim/tax.py`): نموذج قائم على الوكلاء لـ 5000 دافع ضرائب.
- كل شخص يختار كم يصرّح من دخله حسب نموذج Allingham–Sandmo (بصيغة Yitzhaki)، مع كلفة أخلاقية تزيد مع حجم الإخفاء.
- الموظفون الذين يبلّغ صاحب العمل عن رواتبهم لا يستطيعون الإخفاء تقريباً.
- الناس يتعلّمون من تجاربهم وتجارب زملائهم في القطاع.
- مصلحة الضرائب تدقق عشوائياً أو بالاستهداف، اعتماداً على مؤشر غير دقيق للدخل.
- تتحكم بنسبة الضريبة والغرامة ونسبة التدقيق والاستهداف، وتقارن 25 سيناريو.

**الاحتيال المالي** (`mizan/fraudsim/ledger.py` و `detection.py`):
- سجل يحتوي قرابة 50 ألف معاملة، حُقنت فيه أنماط معروفة من أدلة FATF: تجزئة الإيداعات، وتدوير الأموال، والفواتير الوهمية، والحسابات الوسيطة.
- أدوات الكشف: قانون بنفورد، وقاعدة التجزئة، والبحث عن الدوائر المغلقة، وقاعدة المبالغ المستديرة، وقاعدة الحسابات الوسيطة مع تتبع الأموال، ونموذج انحدار لوجستي مكتوب بـ numpy.
- تقيس دقة كل أداة واستدعاءها على حسابات اختبار محجوزة.
- **معامل التمويه** يُظهر كيف تنهار القواعد الثابتة عندما يتكيّف المحتالون: استدعاء القواعد ينخفض من 100% إلى نحو 20%، بينما يبقى النموذج المدرَّب قرابة 90%.
